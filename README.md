# TALON Foot Scan Web Application — Public Showcase

This repository contains a deliberately limited public showcase of the TALON Foot Scan web application.

## Public content

- Responsive React landing page
- Product positioning and customer journey overview
- Reusable UI styling and animation examples

## Kept private

- Medical questionnaire and assessment logic
- AI prompts, image-analysis pipeline, and scoring rules
- Backend services, database schema, authentication, and admin tools
- Customer records, uploaded photos, credentials, and deployment configuration

The production product is not open source. This repository demonstrates the public-facing interface while protecting customer privacy and business IP.

## Local preview

```bash
npm install
npm run dev
```
